# Base de datos - Austral

Esta carpeta contiene todos los recursos relacionados con la base de datos del proyecto.

## Estructura

```text
database/
│
├── schema/
├── seeds/
└── diagrams/
```

## Contenido

- **schema/**: Script SQL para crear la base de datos.
- **seeds/**: Datos iniciales del sistema.
- **diagrams/**: Diagramas entidad-relación (ERD).

## Motor de base de datos

- MySQL 8
- phpMyAdmin
